# Python Basics Demonstration

This project is a simple Python script showcasing fundamental concepts such as strings, lists, tuples, sets, and loops. It is designed as a practice file to demonstrate how Python handles data structures, string manipulation, and control flow.

📌 Features Demonstrated
1. String Operations
- Creating and printing strings
- Measuring length and type of a string
- Indexing and slicing (string[1:5], string[::-1])
- String methods: .lower(), .upper(), .split(), .count()
- String concatenation and repetition
- Membership testing ('z' in myfirststring)
2. List Operations
- Creating lists and appending elements
- Removing elements with .pop() and .remove()
- Sorting lists in reverse order
- Nested lists and mixed data types
3. Tuple Operations
- Creating tuples
- Accessing elements
- Checking type and length
4. Set Operations
- Union (a | b)
- Intersection (a & b)
- Difference (b.difference(a))
5. Conditional Statements
- Using if statements to check conditions
- Printing formatted strings with f-strings
6. Loops
- Iterating through lists with for loops
- Calculating squares of numbers
- Generating multiplication tables
- List comprehensions for generating sequences

🎯 Purpose

- String manipulation
- List, tuple, and set operations
- Conditional logic
- Iterative loops and comprehensions
